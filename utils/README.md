utils/

Purpose
- Collection of small helper scripts, demos and notebooks for exploration, inference, and data inspection.

Contents (examples)
- `demo.py`, `generate_synth.py`, `measure_frames.py`: small utilities used during development.
- `explore_*.ipynb`: notebooks for exploring encoders, Lhotse datasets, and processors.

Usage
- Notebooks are interactive; run locally in a configured venv.
- Utilities are lightweight; read header comments for invocation examples.
